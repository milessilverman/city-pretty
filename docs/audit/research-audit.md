# Research library & case-study audit (2026-11-16)

Scope: `app/data/research.json` (52 records before this audit), `data/research_corpus_500.json` (was a byte-identical copy of research.json; now rewritten to the same output), `app/data/case_studies.json` (8 records).

## Rules used

- **verified**: citation confirmed through the Crossref API this session **and** the displayed `impact` text is a verbatim quote from an abstract or page fetched this session.
- **partially_verified**: the work (or the publisher page) exists, but no claimed effect size could be confirmed, so `impact` is null or replaced with fetched text.
- **could_not_check**: the source URL failed (403/404/connection error) and no DOI exists. Existence is **not** confirmed. All numbers are nulled.
- **removed**: no real work matching the claimed authors and topic was found, usually because the DOI did not exist or pointed to an unrelated paper.
- Nothing was filled in from memory. Sources: Crossref REST API, Semantic Scholar API, one OpenAlex call (then the shared daily quota ran out), and curl fetches of the listed URLs. Wikipedia, OpenAlex and several .gov/.org sites were rate-limited or blocked from this environment.
- Every `vpd` ("$ return per $1") value was removed. No fetched source states any of them. `takeaway` text was removed for the same reason. The originals are kept in each record under `verification.removed_unverified_claims`.

Of the 33 records that carried a DOI, only 3 resolved to the paper claimed: Crompton 2001, Cervero & Duncan 2002 and Branas et al. 2018. About 13 DOIs resolved to unrelated papers, including gravel excavation, synthetic estrogens, cloud removal in Landsat imagery and power-line radiation. The rest did not exist.

Where a claimed number could be checked against a fetched abstract, it was usually wrong:
- transit_001 claimed +18.8% to +38.2% for commercial parcels. The abstract says about 23% near light rail and over 120% near commuter rail.
- bike_003 claimed "+0.9% per Walk Score point". The abstract says a 10-point increase raises values 1-9%.
- safe_001 claimed "+12% home values". The abstract reports no home-value result.

## Known follow-ups (not done here)

- `app/app.js` research modal: it prints `Return: $${s.vpd} / $1`, which now renders "$null / $1". The average line uses `x.vpd || 1.8`, a made-up default. Every link with a `source_url` is labeled "Verified Source", including could_not_check records. The UI should show `verification.status` instead.
- `app/app.js` case-study map tooltip divides `proj.publicCost/1e6`, so null displays as "$0.0M".
- `tests/unit/dataAccuracy.test.ts` tests 1 and 4 assert ">= 50 studies" and a `last_verified` date on every record. They will fail, and they encode the false claim that these records were verified. They should be rewritten to enforce `verification.status`.
- Re-run when rate limits reset. OpenAlex and Wikipedia can supply abstracts and secondary checks, and the could_not_check URLs can be retried from a browser or a network that is not blocked.
